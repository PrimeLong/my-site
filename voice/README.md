# Озвучка эфиров «Слушай» (FreeTTS или другой сервис)

Голосом в приложении читаются только эфиры уроков «Слушай». Их ведёт Лада Звонарёва:
**52 сюжета, около 7 200 символов**, все они в файле [`host.txt`](host.txt). «История» —
лента для чтения, её озвучивать не нужно.

Пока записи нет, сюжет читает голос браузера, как раньше. Когда запись появляется, урок
играет её, подсвечивает слова по ходу записи и подписывает эфир «голос синтезирован».
Если запись не загрузится, сюжет прочитает браузер.

## Как озвучить

1. Откройте FreeTTS и выберите **один русский женский голос** на все сюжеты: это одна
   ведущая. Подойдёт бодрый тон, темп обычный или чуть быстрее.
2. Возьмите сюжет из `host.txt`, вставьте текст в сервис, озвучьте и скачайте MP3.
3. Переименуйте файл в имя из строки `файл:` над этим сюжетом, например
   `host-18va1k1.mp3`. Имя пишется маленькими буквами, ровно как в списке.
4. Сложите файлы в папку `public/voice/`. На GitHub: откройте `public/voice` →
   **Add file → Upload files**, перетащите все MP3 и нажмите **Commit changes**.
5. **Выровняйте громкость:** `npm run voice:normalize` (нужен ffmpeg) — речь −16 LUFS, пик не выше
   −1,5 dBTP, моно, 56 кбит/с, без обложки; `npm run voice:normalize -- --check` только проверяет. Без
   этого шага сюжет играет на громкости сервиса: у FreeTTS это около −26 LUFS — заметно тише книг.
6. Vercel соберёт сайт сам. После сборки уроки играют записи, и ничего больше
   перечислять не нужно.

Записывать всё сразу не обязательно: можно положить часть файлов, а остальные сюжеты
прочитает браузер.

## Полезно знать

- **Произношение.** Имя файла считается по тексту урока, а не по тексту, который вы
  вставили в сервис. Поэтому текст для озвучки можно править: ставить ударения так, как
  их понимает сервис, или писать числа словами. Имя от этого не изменится.
- **Размер.** Хватит моно MP3 на 48–64 кбит/с. Сюжет длится около 10 секунд и занимает
  примерно 80 КБ, все 52 сюжета — около 4 МБ.
- **Текст сюжета поменяли.** У сюжета появится новое имя файла, а старая запись
  перестанет играть: устаревший текст не прозвучит. Команда `npm run voice:export`
  (или просьба к Claude) обновит эту папку. Записанные сюжеты в ней отмечены `✓`, а
  устаревшие файлы перечислены, чтобы их можно было удалить.
- **Лицензия.** Перед публикацией проверьте в условиях FreeTTS, можно ли выкладывать
  записи на сайт. Под эфиром всегда видна подпись «голос синтезирован».

`lines.csv` — тот же список в виде таблицы (кодировка UTF-8, разделитель `;`).
